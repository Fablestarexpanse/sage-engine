- **M3 S3b design (owner rulings):** memory importance comes from deterministic rules, with optional per-kind weights in the mind (the model may re-rate through reflection later). Reflection triggers when the summed importance of new memories passes a threshold; the model writes 1-3 reflections stored as `sage.mind.reflected` occurrences that only the agent perceives. Plans are deferred. Build order: (1) component upcasters, `sage.mind` v2, importance, lexical retrieval; (2) embeddings and cache; (3) reflection.

- **M4 S3 plan (owner rulings):** cards first. S3a: fuzzed PNG chunk parser and Tavern Card v1/v2/v3 import into an agent. S3b: `.sagepkg` (tar+zstd) and `sage install` from a local file.
