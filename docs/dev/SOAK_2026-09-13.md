## Fix pass (same day) and reset
All seven bugs and the balance items above were addressed, then every agent was
reset for soak 2 (soak-1 logs and agent rows archived to `logs/soak-2026-09-13/`):
- Trade crash: kind→direction; `log_event`'s event type is now positional-only
  so a field named `kind` can never collide again (regression test added).
- Rent: timed leases (`rentals` hash holds tenant + expiry, swept every ~60 s,
  renew within 15 min of expiry); lodging blocks on desk rooms; new Tidewater
  Bunkhouse (4 beds, 8 Digi / 60 min) beside the AIpub apartments (15 / 80 min);
  agents only walk to a desk that has a free bed they can afford. Lease claims
  are serialized — the first post-reset run caught three agents leasing the
  same bunk in one concurrent tick.
- Self-dealing: keepers can't buy from or sell to their own counter; keeper
  takings go through an atomic `digi_pending:<name>` counter.
- Wounded agents (<50% hp) retreat to home or clinic before anything else;
  hunting requires ≥70% hp; contracts abandoned after 6 trips at <half progress.
- Starving + broke agents forage (search spots that yield rations).
- Agents sell when the pack reaches 12 items, at the best-paying buyer; buy
  food at the cheapest seller (Meri's store now competes with the AIpub).
- Pathfinding XP: 60% on a first visit, 4%/(1+level/5) on familiar ground.
- Work spreads across all willing factions.
- Brain runs as a background task (LLM no longer awaited inside the tick);
  agents plan occasionally with no human present; rejected plans are logged
  (`intent_rejected`) and the intent prompt names valid targets per goal.
- Agent ticks run concurrently (`asyncio.gather`).
- Tests no longer write to the live telemetry log (`tests/conftest.py`).
- Reset: agent_state rows deleted, agent Redis state/leases/ledgers/heatmaps
  cleared, persona gear removed (agents start empty-handed with their persona
  starting wallets and attribute spreads).

Found after the fix: a pawn keeper pays for buy-backs but never resells the goods,
so owning the pawn shop is a pure money sink (Aldo 112 → 8 Digi in 4 minutes).
